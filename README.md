# 🔐 NoteVault

NoteVault is a secure note-taking web application built using **Flask**, **MySQL**, and **Bootstrap**.

Users can create an account, log in securely, and manage their personal notes.

---

# 📌 Features

- User Registration
- User Login
- Secure Password Hashing
- Session Management
- Add Notes
- Delete Notes
- Responsive User Interface
- Flash Messages

# 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Ragss07/NoteVault.git
```

### 2. Open the project

```bash
cd NoteVault
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows

```bash
venv\Scripts\activate
```

### 5. Install the required packages

```bash
pip install -r requirements.txt
```

### 6. Configure MySQL

Create a MySQL database and update the database credentials in `db.py`.

### 7. Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
